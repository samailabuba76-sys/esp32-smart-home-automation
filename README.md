# Microcontroller Based Voice Recognition Smart Home System

**Final Year Project - IoT Smart Home**

Live Dashboard: https://smart-homes-project.netlify.app

### Features
- Voice Control: "Socket on", "Fan on", "All lights off"
- 4-Channel Relay Control via ESP32-S3
- Firebase Realtime Database
- Responsive White Dashboard (Netlify)
- All ON/OFF, Status sync

### Tech Stack
- ESP32-S3 + 4CH Relay
- Firebase RTDB: smart-home-4584a
- HTML/CSS/JS Frontend
- Netlify Hosting
- Web Speech API

### How It Works
Web UI -> Firebase (lamp1, lamp2, fan, socket) -> ESP32 polls every 0.8s -> Relay control
